Original script (paper/scripts/) -> release script | what it produces | run-record groups read (under <records>/runs/ unless stated)
All scripts: first argument = records directory (or "-" for $SPI_RECORDS); layout in records.py. Run from this directory.
Seeds: Qwen2.5-1.5B 0,1,2,4-9; other models 0-3 (Llama-3.1-8B up to 0-7 where run); re-ask reruns <group>_rk_s<seed> replace the originals.
